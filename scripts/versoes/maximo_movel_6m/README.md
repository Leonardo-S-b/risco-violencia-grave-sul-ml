# Versao anterior: maximo movel nos proximos seis meses

Esta pasta preserva o pipeline anterior para rastreabilidade academica. O target
indicava se algum dos seis meses futuros superaria o maximo mensal conhecido nos
12 meses anteriores.

Ela contem criacao do target, comparacao de algoritmos, balanceamento,
otimizacao, estabilidade, analise de limiares e a avaliacao final que ja foi
aberta. Nao e a versao escolhida para a futura API.
